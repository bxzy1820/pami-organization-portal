## 2. 部署结构

```text
公网 :80 /pami/
  → 宿主机 Nginx
  → 127.0.0.1:18081
  → pami-portal-frontend
  → pami-portal-backend:3000
  → pami-portal-db:3306
```

PAMI 使用独立 Docker 网络和独立 MySQL 数据卷，没有复用或修改服务器原有应用数据库。

## 3. 容器

| 容器 | 作用 | 公网暴露 |

| `pami-portal-backend` | Express API | 否 |
| `pami-portal-db` | MySQL 8.0 | 否 |

## 5. 运维命令

```bash
cd /home/ubuntu/apps/pami-organization-portal
sudo docker compose --env-file .env.deploy ps
sudo docker compose --env-file .env.deploy logs --tail=200
sudo docker compose --env-file .env.deploy restart
```

Nginx 配置备份：

```text
/etc/nginx/sites-available/zhiyin.pre-pami-20261106-201839
```

回滚 Nginx 路由：

```bash
sudo cp -a /etc/nginx/sites-available/zhiyin.pre-pami-20261106-201839 /etc/nginx/sites-available/zhiyin
sudo nginx -t
sudo systemctl reload nginx
```

停止 PAMI 容器但保留数据库数据：

```bash
cd /home/ubuntu/apps/pami-organization-portal
sudo docker compose --env-file .env.deploy down
```
