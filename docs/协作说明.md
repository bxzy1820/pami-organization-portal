# 协作说明

## 提交格式

```text
feat: 新增功能
fix: 修复问题
docs: 修改文档
refactor: 重构但不改变功能
chore: 工程或依赖调整
```

## 合并流程

1. 从 `develop` 创建个人功能分支。
2. 完成功能并自行测试。
3. 提交合并请求到 `develop`。
4. 由组长检查接口、页面和敏感信息。
5. 周四验收后将 `develop` 合并到 `main`，创建 `v1.0.0` 标签。

## 一期验收链路

```text
管理员登录
→ 新建或编辑内容
→ 写入数据库
→ 发布后门户展示
→ 下架后门户隐藏
```
