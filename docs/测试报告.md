## 3. Prisma 验证

执行：

```bash
npm run db:validate
npm run db:generate
```

结果：

```text
Prisma schema valid
Prisma Client generated successfully
```

集成检查中修复：

- `SiteSetting.shortName` 的可空定义与迁移 SQL 不一致。
- Seed 导入脚本将 `orgName` 错传给 Prisma；已改为模型字段 `name`。
- `external_links.name` 用于 upsert，但原模型缺少唯一约束；已在 Prisma、迁移和兜底 SQL 中统一补充。
