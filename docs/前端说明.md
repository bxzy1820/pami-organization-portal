# 葩米科技 · 组织门户 前端说明

版本：1.1.0　｜　更新日期：2026-11-06

---

## 1. 项目概述

雄安葩米的组织门户前端，用于对外展示组织概况、研究方向与项目成果，并作为统一访问入口。

- Vue 单页应用（SPA），通过七个公开 API 读取站点、首页、关于、业务、项目、动态和招聘数据
- 请求失败时保留必要的本地展示兜底，并明确显示加载、错误或空数据状态
- 视觉语言参照 bytedance.com：黑白灰为主、单一品牌蓝点缀、大字号与大面积留白、细线分隔
- 已适配电脑与手机，支持键盘操作与「减少动效」偏好

## 4. 页面与路由

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 首页 | 全屏 Hero（打字机标语 + 延迟出现的圆形按钮）→ 栏目目录 → 页脚 |
| `/about` | 关于我们 | 使命 / 文化（轮播 + 折叠）/ 团队 / 路径 / 办公地点 |
| `/business` | 研究方向 | 四条研究主线 + 合作方式折叠 |
| `/projects` | 项目成果 | 占位说明 + 栏目规划 |
| `/news` | 动态 | 公告动态列表及分页 |
| `/recruitment` | 加入我们 | 招聘信息列表及分页 |
| `/404` | 页面不存在 | 路由未匹配时显示，并展示当前访问地址 |

已下线并重定向的旧地址：`/team`、`/contact` 回到首页，`/join` 跳转到 `/recruitment`。
`/index.html` 也会重定向到 `/`，兼容预览工具或静态服务器默认入口。

浏览器标题由路由 `meta.title` 自动生成：`页面名 · 葩米科技`。

## 5. 内容维护

站点业务数据以公开 API 为准，`src/data/site.js` 仅保存导航、展示结构和接口失败时的兜底内容。

| 字段 | 作用 |
| --- | --- |
| `name` / `shortName` | 组织全称 / 简称（Logo、标题、版权） |
| `uscc` | 统一社会信用代码（页脚） |
| `region` / `park` / `address` / `addressNote` | 注册地、园区、地址 |
| `contact.email` | 对外邮箱，留空则不展示 |
| `slogan` | 一句话定位（页脚简介已移除，暂作备用） |
| `intro` | 组织简介长文本 |
| `hero.titleLines` | 首页打字机标语，数组每项一行 |
| `about` | 关于页：`mission` / `culture` / `values` / `collaboration` / `team` / `journey` / `place` |
| `team` | 团队三块（标题、说明、标签） |
| `business` | 研究方向（标题、摘要、要点） |
| `navigation` | 顶部与页脚导航 |
| `externalLinks` | 外链（`primary: true` 会显示在页头） |
| `sections.projects` | 项目成果栏目文案 |

修改建议：

- 数组项可自由增删，页面会自动排列编号（01、02…）
- `about.culture.quoteLead` / `quoteTeam` 是**三段式数组**，中间一项为渐变高亮词，顺序不要调整
- 标注「待确认」的文案为初版占位，上线前需替换为组织确认的表述
- **财务信息（银行账户、开户行、账户编码）不要写入本文件**，门户不对外公示

## 7. 组件说明

| 组件 | 职责 | 关键点 |
| --- | --- | --- |
| `AppHeader.vue` | 固定页头 | 首页顶部透明（白字），其余页面直接白底黑字；切换无渐变，避免白字压白底的瞬间 |

| `v-reveal` 指令 | 滚动揭示 | 进入视口淡入上移 28px，可传延迟毫秒做错峰；`prefers-reduced-motion` 下自动跳过 |

- 跳过导航链接（`跳到主要内容`）
- 导航、抽屉、手风琴均带 `aria-expanded` / `aria-controls` / `aria-current`

- 目标浏览器：Chrome / Edge / Safari / Firefox 最近两个大版本

## 10. 构建与部署

```bash
npm run build      # 产物在 dist/
```

### 部署要点

1. **History 模式需要服务端回退**：所有未命中的路径返回 `index.html`，否则刷新 `/about` 会 404。
2. 静态资源带 hash，可长期缓存；`index.html` 建议不缓存。

Nginx 示例：

```nginx
server {
  listen 80;
  server_name portal.example.com;
  root /var/www/pami-portal;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }

  location ~* \.(js|css|svg|png|jpg|woff2)$ {
    expires 30d;
    add_header Cache-Control "public, immutable";
  }
}
```

3. 若部署在子路径（如 `/portal/`），需在 `vite.config.js` 增加 `base: '/portal/'`，并同步调整路由 base。
4. 站点 `meta description` 在 `index.html` 中，可按需改为正式文案。
