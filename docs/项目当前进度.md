## 3. 后端已交付内容

### 3.1 公开接口

一期暂不实现登录和 JWT，以下公开查询接口无需鉴权：

| 方法 | 接口 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/site` | 站点基础信息 |
| GET | `/api/v1/home` | 首页内容 |
| GET | `/api/v1/about` | 关于我们 |
| GET | `/api/v1/business` | 业务或研究方向 |
| GET | `/api/v1/projects` | 项目成果 |
| GET | `/api/v1/news` | 新闻动态，支持分页 |
| GET | `/api/v1/recruitment` | 招聘信息，支持分页 |

分页契约已经统一为：

- 请求参数：`page`、`pageSize`
- `page` 默认值为 `1`，最小值为 `1`
- `pageSize` 默认值为 `20`，取值范围为 `1` 至 `100`
- 分页数据结构：`{ items, total, page, pageSize }`

统一成功响应格式：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

## 8. 联调启动说明

### 8.1 后端与数据库

```powershell
cd backend
Copy-Item .env.example .env
npm install
npm run db:generate
npm run db:migrate:deploy
npm run db:reset:mock
npm run dev
```

需要先修改本地 `.env` 中的 `DATABASE_URL`，确保 MySQL 已启动且数据库账号可用。

后端默认地址：

- 服务地址：`http://localhost:3000`
- API 前缀：`http://localhost:3000/api/v1`
- Swagger：`http://localhost:3000/api-docs`

### 8.2 前端

```powershell
cd frontend
npm install
npm run dev
```

前端默认开发地址通常为 `http://localhost:5173`。联调时需要确认前端 API 基础地址指向 `http://localhost:3000/api/v1`，并确保后端 `CORS_ORIGIN` 与实际前端地址一致。
